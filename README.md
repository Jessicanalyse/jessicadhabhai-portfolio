# Jessica Dhabhai Portfolio

A simple three-page GitHub Pages portfolio website.

## Files

- `index.html` — About Me page and default landing page
- `skills.html` — Skills & Projects page
- `achievements.html` — Achievements page
- `style.css` — Shared styling
- `assets/jessica-photo.jpeg` — Profile photo

## Publish with GitHub Pages

1. Create a public GitHub repository.
2. Upload all files while preserving the folder structure.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/root` folder, then save.
6. Your website will be available at the GitHub Pages URL provided by GitHub.
